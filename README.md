# Advanced Calculator (C - Console Based)

A console-based Advanced Calculator written in C that performs multiple arithmetic operations using user input from the terminal.

## Supported Operators

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Modulus (%)
- Power (^)
- Increment (++)
- Decrement (--)

## Features

- User-friendly console interaction
- Fast execution
- Handles multiple operations
- Built using basic C concepts (switch-case, loops, functions)

## Technology Used

- C Programming Language
- GCC Compiler
- Terminal / Command Prompt

## How to Run

1. Clone the repository:
   git clone https://github.com/dipanshu-kashyap00/Advanced-Calculator.git

2. Go to project folder:
   cd Advanced-Calculator

3. Compile the program:
   gcc calculator.c -o calculator

4. Run the program:
   ./calculator

## How It Works

- User enters numbers.
- User selects an operator.
- Program performs calculation.
- Result is displayed in the console.
